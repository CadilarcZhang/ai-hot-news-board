# Z.ai MCP 工具充值指南

## 🎯 快速导航

### 方式一：通过 Z.ai Chat

1. **打开主站**
   - 访问：https://chat.z.ai
   - 点击页面上的"登录"或"Sign in"按钮

2. **登录后查找**
   - 在页面右上角或菜单中查找：
     * "账户" / "Account"
     * "设置" / "Settings"
     * "定价" / "Pricing"
     * "订阅" / "Subscription"

3. **可能的页面路径**
   - https://chat.z.ai/account
   - https://chat.z.ai/dashboard
   - https://chat.z.ai/settings

### 方式二：通过 Z.ai 官网

1. **访问官网**
   - 主站：https://z.ai
   - API 文档：https://z.ai/model-api

2. **查找导航菜单**
   - 查找 "Pricing"（定价）
   - 查找 "Console"（控制台）
   - 查找 "Developer"（开发者）

### 方式三：智谱 AI（备用）

由于 Z.ai 与智谱 AI 有关联，也可以尝试：

1. **智谱 AI 开放平台**
   - https://open.bigmodel.cn
   - 登录后访问：https://open.bigmodel.cn/usercenter/balance

2. **余额中心**
   - 查看当前余额
   - 进行在线充值

## 📧 联系官方

如果以上方式都无法找到充值入口，可以直接联系：

**邮箱：** user_feedback@z.ai

**说明内容：**
- 需要为 MCP 工具充值
- 当前显示"余额不足或无可用资源包"
- 询问具体的充值方式和套餐价格

## 🔍 页面关键词

在页面中查找以下关键词：
- 充值 / Top up / Recharge
- 价格 / 定价 / Pricing
- 套餐 / 订阅 / Plan / Subscription
- 账户 / 余额 / Account / Balance
- 支付 / Payment

## 💡 提示

1. 大多数 AI 服务都需要先注册/登录账号
2. 充值页面通常在个人中心或账户设置中
3. 注意选择适合自己使用量的套餐
4. 充值后 MCP 工具会自动恢复使用
